# Statistical Process Control (SPC)

SPC is used to ensure that processes - in manufacturing, service or elsewhere - stay "in statistical control", i.e. within reasonable limits of variation.
The behaviour of such processes is described mathematically using **control charts**, which are then used for further analysis.

## Navigation

Each file is related to a specific kind of control chart.
* xbar, R and s control charts
* CUSUM control chart
* EWMA control chart
